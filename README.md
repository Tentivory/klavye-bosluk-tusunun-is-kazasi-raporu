1. Boşluk tuşunun basılma sayısını resmi kaza olarak tescil etmek.  
2. Enter tuşunun yıllardır göz yumduğu mobbingi belgelemek.  
3. Caps Lock'un gereksiz yere bağırmasını tanık ifadesine dönüştürmek.  
4. Kullanıcının "bir daha basmam" sözünü yeminli beyana çevirmek.

## Çalıştırma

